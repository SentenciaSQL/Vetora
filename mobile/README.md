# Vetora mobile

Aplicación Flutter para propietarios de mascotas. Comparte la API REST `/api/v1` con el panel Angular.

```bash
cd mobile
flutter create . --project-name animalin --org com.animalin
flutter pub get
flutter run --dart-define=API_URL=http://10.0.2.2:8080/api/v1
```
